About Thyme

Thyme is a timeline browser. It started as an IMDB clone and grew into a place to compare when things happened across datasets: film and television, baseball and basketball, music releases, and the lives of notable people from Wikidata, with more sources on the way (see Sources).

How it is built

  • TrailBase serves the API and the static pages from one SQLite database in traildepot/. The custom endpoints (/search, /timeline…) are a WASM component compiled from TypeScript in wasm/src/.
  • One events table. Every source becomes rows in entities and events (instants and spans, with a year, a precision and a rank). Precomputed level-of-detail tables pick the top events per year, decade and century so a wide view costs the same whether the database holds sixty thousand events or sixty million.
  • Ingest. scripts/ingest_events.py syncs each source from the files under data/, fingerprinting them so unchanged sources are skipped, then links the same entity across sources through Wikidata ids, external identifiers and names with dates.
  • Pages are static HTML rendered from templates/, hydrated with Alpine.js; the timeline itself is a small TypeScript app in web/.

Source code: github.com/mburns/thyme.
